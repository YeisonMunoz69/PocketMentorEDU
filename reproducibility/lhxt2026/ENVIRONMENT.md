# Entorno de verificación

El paquete se comprobó localmente el 24 de septiembre de 2026 con:

- Windows 11, arquitectura x86-64.
- Python 3.13.5.
- NumPy 2.4.6.
- SciPy 1.17.0.
- Matplotlib 3.10.8.
- Pillow 12.1.1.
- SciencePlots 2.2.2.

Estas versiones corresponden a la verificación y regeneración del paquete público. No se presentan como un registro retrospectivo del entorno original de todas las ejecuciones. Las condiciones de inferencia documentadas en el artículo fueron un equipo Intel Core i5 con 8 GB de RAM, SSD SATA, ventana de 4096 tokens y ejecución sin GPU desde una memoria USB.
